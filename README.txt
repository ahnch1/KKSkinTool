KKSkinTool — Koikatsu 바디 스킨(탠라인 파츠 / 타투) 배치 도구  (C# WinForms, VS2022, .NET 8)

[빌드]  KKSkinTool.sln 열기 → 빌드 (Visual Studio 2022 17.8 이상, ".NET 데스크톱 개발")

[작업 순서]
1. 처음 실행하면 베이스 와이어프레임(wireline.png)을 고름 (다음부터 자동으로 불러옴)
2. 도구 모음 "배경"에서 흰색(탠라인) / 투명(타투)을 고르고 [새 문서]
3. [파트 불러오기] (Ctrl+O) → 탠라인 파츠(top_*.png, bottom_*.png)나 타투 PNG 선택
   - 2048 전체 크기 파츠는 제자리에, 작은 이미지는 화면 가운데에 놓임
   - 불투명 PNG는 "어둡게", 투명 PNG는 "일반" 합성으로 자동 설정
4. 마우스·속성 패널로 위치/크기/회전/불투명도/좌우 반전 조절
5. [확정] (Enter) → 결과에 반영. 다른 파트를 계속 불러와 반복
6. [PNG 저장] (Ctrl+S)

[TOP × BOTTOM 일괄 조합]  (도구 모음 버튼 또는 Ctrl+B)
- TOP 폴더, BOTTOM 폴더, 저장 폴더를 지정하고 [조합 시작]
- 모든 조합을 "어둡게"(또는 곱하기)로 합쳐 TOP_BOTTOM.png로 저장
  예) top_triangle.png + bottom_cheeky.png → triangle_cheeky.png
  ("파일명 접두어 제거"를 끄면 top_triangle_bottom_cheeky.png)
- 이름이 _ 로 시작하는 파일(_overview_on_uv.png 등)은 제외
- 이미지 크기가 문서와 다르면 문서 크기(베이스 크기)로 맞춰서 합성, 투명 부분은 흰색으로 처리
- 진행률 표시, [중지]로 중단 가능. 폴더 경로는 다음 실행 때 기억

[유동화]  (도구 모음 "유동화" 또는 L)
- 확정된 결과 이미지를 브러시로 변형 (배치 중인 파트가 있으면 먼저 확정/취소를 물어봄)
- 도구: 밀기, 부풀리기, 오므리기, 소용돌이(시계/반시계), 매끄럽게, 복원  (숫자키 1~7)
- 왼쪽 드래그로 적용. 부풀리기·오므리기·소용돌이·복원은 누르고 있으면 계속 적용
- 브러시 크기: [ / ] 또는 Alt+휠, 패널에서 크기·강도 조절
- 유동화 중 Ctrl+Z: 획 단위 실행 취소 (최대 40획), [전체 복원]: 시작 상태로
- Enter 적용 / Esc 취소. 적용 후에는 문서 Ctrl+Z 한 번으로 유동화 전체를 되돌림
- 원리: 시작 시점 이미지를 원본으로 두고 "가져올 위치"(변위)만 편집 → 결과는 원본에서 한 번만
  다시 샘플링하므로 여러 번 문질러도 흐려지지 않음

[조작]
파트 안 드래그: 이동          모서리 사각형: 크기          주황 원: 회전 (Shift: 15° 단위)
방향키: 1px 이동 (Shift 10px)  Alt+휠: 크기               Alt+Shift+휠: 회전
휠: 확대/축소                  가운데·오른쪽 드래그 또는 Space+드래그: 화면 이동
Ctrl+0 화면 맞춤 / Ctrl+1 100% / Ctrl+ +,- 확대·축소 / W 와이어 표시 전환
Enter 확정 / Esc 취소 / Ctrl+Z 실행 취소 / Ctrl+Y 다시 실행 / Ctrl+N 새 문서

[실행 취소 규칙]
- 파트 배치 중: Ctrl+Z는 그 파트의 이동/크기/회전을 한 단계씩 되돌림
- 파트가 없을 때: 마지막 확정을 되돌림 (최대 12단계), Ctrl+Y로 다시 실행

[합성 방식]
어둡게(탠라인): 결과와 파트 중 더 어두운 값. 탠라인 파츠끼리 겹쳐도 진해지지 않음
곱하기: 겹치면 더 진해짐
일반(타투): 알파 합성

[기타]
- 와이어프레임은 화면 표시용이며 저장 결과에는 들어가지 않음
- [결과 열기]로 저장했던 PNG를 불러와 이어서 작업 가능 (확정된 파트는 다시 움직일 수 없음)
- 설정(베이스 경로, 마지막 폴더)은 exe 옆 kkskintool_settings.txt

[코드 구성]
CanvasView.cs  화면 표시, 확대/이동, 핸들 드래그
PartLayer.cs   파트 이미지 + 변환 상태(PartState)
Doc.cs         결과 레이어, 확정, 실행 취소/다시 실행
Pixels.cs      픽셀 연산 (어둡게/곱하기 합성, 와이어 오버레이)
MainForm.cs    도구 모음, 속성 패널, 단축키
BatchCombine.cs  TOP × BOTTOM 일괄 조합 (로직 + 창)
Liquify.cs     픽셀 유동화 (변위 필드, 브러시 도구, 획 단위 실행 취소)
